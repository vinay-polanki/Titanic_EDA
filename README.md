# Titanic_EDA

## Titanic Dataset – EDA & Classification (Logistic Regression & Decision Tree)

This was my first real hands-on project where I explored Python, pandas, and basic machine learning. Using the well-known Titanic dataset, I dove into the data to understand which factors might have influenced passenger survival—like Age, Gender etc.,

In this project, I:
	•	Cleaned the data and filled in missing values
	•	Explored patterns visually with matplotlib and seaborn
	•	Created new features to improve model accuracy
	•	Built and tested both Logistic Regression and Decision Tree models
	•	Evaluated the results using confusion matrices and classification reports

It was a great learning experience that helped me get comfortable with Python syntax, data manipulation using pandas, and the overall flow of a machine learning project.
